# Ujjwal Yadav — Personal Portfolio

A static portfolio with a scroll-controlled portrait turn, a 3D project gallery,
nine filterable project cards, and the downloadable résumé.

## Publish with GitHub Pages

1. Create a public GitHub repository named `portfolio`, or choose a new repository name.
2. Upload the contents of this folder to the repository. `index.html` and `assets/` must be at the repository root, not inside another folder. Upload the extracted files, not the ZIP itself.
3. Commit the upload to `main`.
4. Open **Settings → Pages**.
5. Set **Source** to **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish and open the website URL shown in those settings.

For the account `Ujjwal-verse` and repository `portfolio`, the expected address is
`https://ujjwal-verse.github.io/portfolio/`. This address becomes available only after deployment succeeds.

GitHub Pages settings reference:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit the site

- `index.html`: page text, sections, and résumé links.
- `styles.css`: layout, colors, responsive styling, and motion fallbacks.
- `projects.js`: the details opened by project cards.
- `app.js`: navigation, filters, dialogs, and scroll behavior.
- `portrait-sequence.js`: portrait image sequence.
- `assets/`: portrait frames, project images, and the résumé.

No npm install, build step, API key, database, or external server is required.
All site asset paths are relative, so the same package works on a repository
project URL or on a `USERNAME.github.io` user site.

The original photo remains the front-facing portrait and the reduced-motion
fallback; generated angle images provide the scroll-controlled turn.
